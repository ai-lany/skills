# Inspiration images

Drop reference images here (screenshots, moodboards, photos of things you love), then add a
row to `../../references/inspiration.md` saying what to take from each one.

When a request needs visual grounding (for example "make it feel more like the Y2K one"),
Claude can open these files to look at them. Use your own captures for personal reference.
Don't ship third-party images inside generated sites.
